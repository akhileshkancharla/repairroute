Limitations and use

Existing-fault scope

This model is evaluated on records already known to be faulty.

Historical context

The planner explores capacity trade-offs on a saved historical batch.

Missing values

Source attributes may contain missing values; review data quality before use.

Human decision

Inspect in rank order, then follow workshop procedure for diagnosis.
